# LayoutProvider

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

```tsx
import { LayoutProvider } from '@uigovpe/components'
```

## Props próprias

| Prop | Tipo | Obrigatória | Descrição |
|---|---|---|---|
| `children` | `ReactNode` | sim |  |
| `storageKey` | `string` | não | LocalStorage key to persist collapsed state |
| `breakpoint` | `number` | não | Breakpoint (px) below which the sidebar starts collapsed |
| `template` | `'backoffice' \| 'landingpage'` | não |  |
