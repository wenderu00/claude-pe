# InputText

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

```tsx
import { InputText } from '@uigovpe/components'
```

**Estende** `InputTextProps` de `primereact/inputtext`, exceto `content`. As props de lá também valem.
