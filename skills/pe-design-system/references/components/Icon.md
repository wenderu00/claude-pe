# Icon

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

```tsx
import { Icon } from '@uigovpe/components'
```

**Estende** `DetailedHTMLProps` de `react`, exceto `children`, `ref`. As props de lá também valem.

## Props próprias

| Prop | Tipo | Obrigatória | Descrição |
|---|---|---|---|
| `icon` | `IconName` | sim |  |
| `outline` | `boolean \| undefined` | não |  |
| `size` | `"small" \| "large" \| undefined` | não |  |
| `className` | `string \| undefined` | não |  |
| `styles` | `React$1.CSSProperties \| undefined` | não |  |
