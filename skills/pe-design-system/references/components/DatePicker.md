# DatePicker

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

```tsx
import { DatePicker } from '@uigovpe/components'
```

**Estende** `CalendarProps` de `primereact/calendar`, exceto `selectionMode`. As props de lá também valem.

## Props próprias

| Prop | Tipo | Obrigatória | Descrição |
|---|---|---|---|
| `selectionMode` | `'single' \| 'range' \| 'multiple'` | não |  |
| `locale` | `string` | não |  |
| `invalid` | `boolean` | não |  |
| `disabled` | `boolean` | não |  |
| `label` | `string` | não |  |
| `suportText` | `string` | não | **Obsoleta.** use `supportText` |
| `supportText` | `string` | não |  |
