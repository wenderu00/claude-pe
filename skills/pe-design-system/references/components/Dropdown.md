# Dropdown

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

```tsx
import { Dropdown } from '@uigovpe/components'
```

**Estende** `DropdownProps` de `primereact/dropdown`. As props de lá também valem.
