# AdminUserBar

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

Barra institucional com link para o Governo de Pernambuco e controles de acessibilidade.

```tsx
import { AdminUserBar } from '@uigovpe/components'
```

## Props próprias

| Prop | Tipo | Obrigatória | Descrição |
|---|---|---|---|
| `user` | `User` | sim |  |
| `ui` | `AdminUserBarUiProps` | não | Personalização de classes e estilos por área da barra. |
| `breadcrumb` | `BreadcrumbProps` | não |  |
| `avatarIcon` | `IconName` | não |  |
| `menuActions` | `MenuAction` | não |  |
| `avatarImage` | `string` | não |  |
| `menuMobileAction` | `() => void` | não |  |
