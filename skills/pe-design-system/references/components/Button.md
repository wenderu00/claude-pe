# Button

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

```tsx
import { Button } from '@uigovpe/components'
```

**Estende** `ButtonProps` de `primereact/button`. As props de lá também valem.

## Props próprias

| Prop | Tipo | Obrigatória | Descrição |
|---|---|---|---|
| `tonal` | `boolean` | não |  |
