# Accordion

> Gerado de `@uigovpe/components@1.1.40` por `npm run sync-ds`. Não edite à mão.

```tsx
import { Accordion } from '@uigovpe/components'
```

**Estende** `AccordionProps` de `primereact/accordion`. As props de lá também valem.

## Props próprias

| Prop | Tipo | Obrigatória | Descrição |
|---|---|---|---|
| `items` | `AccordionItem[]` | sim |  |
| `expandIcon` | `IconType<AccordionProps> \| IconName` | não |  |
| `collapseIcon` | `IconType<AccordionProps> \| IconName` | não |  |
| `preserveContent` | `boolean` | não |  |
